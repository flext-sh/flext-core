# Ralph loop

Treat `$ARGUMENTS` as exactly one authorized objective and acceptance boundary.
Refuse an empty request, several unrelated objectives, or work whose required
owner and completion contract cannot be established.

1. Read active project law, architecture, existing implementation, consumers,
   current runtime, canonical tracking contract when available, and native gates.
2. Select one SSOT-level correction. Implement the complete bounded behavior,
   simplify it inline, rewire all affected consumers, and delete the superseded
   path in the same iteration.
3. Exercise the real public runtime, then run the focused and phase-required
   native gates. A warning, skip, missing tool, timeout, auth error, or failed
   cleanup blocks this iteration and the next one.
4. Land only through the active repository integration contract. If tracking,
   review, CI, integration, or post-merge runtime is unavailable, report the
   exact boundary, preserve it only in separately authorized Git/PR/CI evidence,
   create no substitute tracker or ledger, and keep the iteration open.
5. Start another iteration only after the current one meets every active phase
   exit condition.

Return objective, owner, consumer rewiring, removed residue, runtime and gate
evidence, integration state, and the exact blocker or next eligible objective.
